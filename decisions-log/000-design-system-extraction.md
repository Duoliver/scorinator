# Task 0 — decisions log: design-system extraction

Judgment calls made while building `design-system/` (tokens + primitives) that a later session shouldn't silently re-litigate. Condensed here from `PROGRESS.md`'s running Decisions log at the end of the Task 0 session — see `PROGRESS.md`'s Decisions log section for the procedure this follows, and `progress-reports/000-design-system-extraction.md` for the task's overall report.

- **2026-09-02:** `Tabs` owns its active-tab state internally (`defaultTab` + `content` per tab, switches and renders the panel itself) instead of being externally controlled (`activeId`/`onChange` from the caller) — content-switching is the component's core expected behavior, so every consumer shouldn't have to reimplement the same conditional. Kept an optional `onChange` (fires on every switch, e.g. for lazy-loading a tab's data) but deliberately did **not** add a controlled `activeId` override — the one case that needs it (an external actor, e.g. browser back/forward via a route param, forcing the visible tab without a click) isn't a need anywhere in the app yet; add it later if that materializes rather than building the escape hatch preemptively.
- **2026-09-02:** `--color-fg-muted` (#5C5C5C) is kept as-is despite measuring ~6.69:1 on `--color-surface` (short of the Foundations screen's claimed blanket AAA 7:1) — confirmed with the user it's for disabled/de-emphasized elements only, not primary text. See `docs/design-reference/README.md`'s "Known contrast exception" note.
- **2026-09-02:** 16-colour team palette shown in the Foundations screen was deliberately _not_ extracted into `design-system/` tokens — it's explicitly captioned "placeholder... pending final review" and is MVP3 scope. Extract it when MVP3 is approved, not before.
- **2026-09-02:** Styled `design-system/` primitives with plain CSS Modules (Vite's built-in `*.module.css` support) rather than Tailwind. `CLAUDE.md` lists Tailwind in the tech stack, but it isn't installed/configured anywhere in the repo — wiring it is a separate decision, out of scope for this task.
