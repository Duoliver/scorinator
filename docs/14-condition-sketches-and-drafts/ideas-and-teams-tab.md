# US 14 - Team Condition (MVP3) ideas

Written on 2026-11-13 by User

## Condition as a fixed relative instead of random absolute bonus

OVR is already randomised between the tier range. The condition could be fixed absolute then. Whether it rounds up or down from a float point is up to the condition. It would also keep users from switching back and forth for a more randomised output.

| Condition | Output | Round |
| -- | -- | -- |
| +2 | +20% OVR | Ceiling |
| +1 | +10% OVR | Ceiling |
| 0 | 0 | - |
| -1 | -10% OVR | Floor |
| -2 | -20% OVR | Floor |

I acknowledge that stronger teams would get lower lows and higher highs. Thats ok.

## The Teams tab

As an alternative to the "during league team modal", the Teams tab could just list the league teams, with each row having the condition segmented control already in the line, expanded, for an autosaved quick condition switch. I think we could have both ways to do so.
