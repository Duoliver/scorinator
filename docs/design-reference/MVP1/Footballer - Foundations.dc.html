Footballer — Design Foundations

Base components

Neubrutalist system: sharp corners, solid borders, hard offset shadows. All foreground/background and text/accent pairings meet WCAG AAA (7:1+).

Colour

warning · #D9A900

White text sits on accent/error (AAA on both). Warning is used with near-black text only — it's too light for white text to pass AAA.

Typography

Barlow Semi Condensed Bold — dense table headers
