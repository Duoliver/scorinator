# Task 117: CSV v2: the Location and Trigrams columns, the counts for the confirm

**Status:** Done

## Goal

Give the team CSV the two optional MVP2 columns, "Location" (US-09.3) and "Trigrams" (US-09.6). Give Task 119 the counts it shows in the import confirm, "4 new, 8 updated. Continue?", before the import changes anything (Task 75, US-10.2). No screen changes in this task.

## Acceptance criteria

The user agreed these criteria and the six choices below on 2026-10-30.

**The CSV parse (`adapters/csv`):**

- [x] The parse finds the "Location" and "Trigrams" columns by their header, in any order and any letter case, as it finds the other columns.
- [x] A file with no "Location" column gives records with no location. A file with no "Trigrams" column gives records with no trigrams. Both still import.
- [x] A Location cell is trimmed. An empty cell gives `''`. A cell over 40 characters stops the import with an error that names the row.
- [x] A Trigrams cell goes through `parseTrigramList`: split by spaces, letters made uppercase. An empty cell gives `[]`.
- [x] A bad trigram, a duplicate, or more than 5 stops the import with an error that names the row and the problem.

**The CSV export:**

- [x] The export writes six columns: Slug, Name, Colour, Tier, Location, Trigrams. The trigrams are split by one space, for example `ASH AFC`.
- [x] An export, then an import, gives the same records.

**The import (`app/state`):**

- [x] A new Blueprint gets the location and the trigrams of its row, or `''` and `[]` when the file has no such column.
- [x] An updated Blueprint gets the location and the trigrams of its row when the file has the column. With no column, it keeps its own.
- [x] A new function gives the counts of an import, `{ added, updated }`, and changes nothing. It counts by the same rules as `importTeamBlueprints`.

**Code:**

- [x] `TeamListRecord` gets two optional fields, `location` and `trigrams`. No field means "no column".
- [x] Unit tests for each rule above.
- [x] `npm run lint`, `npm run format:check`, `npm run type-check`, and `npm test` pass.

**Out of scope:** the confirm dialog and the Teams screen (Task 119). The drawer fields for Location and Trigrams (Task 119). The team JSON parse: MVP2 does not import the MVP1 team JSON (US-10.3, Task 145). City (MVP3).
